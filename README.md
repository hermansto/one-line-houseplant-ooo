A one-line out-of-office reply, written in the houseplant's own voice.

> I'm out photosynthesizing. I'll water your emails when I'm back. Please hold all meetings until further sunlight.

`main.ts` (Node, stdlib only) writes that single line to `entry.txt` in the output directory, with no trailing newline, and reads it back to verify it matches exactly.
